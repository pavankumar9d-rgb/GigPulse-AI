# Data folder

- `SYNTHETIC_DATA_SPEC.md`: rules for deterministic fictional fixtures.
- `templates/`: header-only CSV templates for manual/authorized sample data.

Never place real platform credentials, raw GPS histories, phone numbers, customer details, order addresses or unredacted private exports in this folder. Keep raw data outside git unless explicit, documented authorization and repository policy permit it. Prefer small, anonymized examples and a dataset manifest.
